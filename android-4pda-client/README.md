# forPDA — неофициальный Android-клиент форума 4pda

Цель проекта: полностью покрыть функционал оригинального форума 4pda, но на
современном стеке (Kotlin + Jetpack Compose + Material 3) и с рядом улучшений
UX, которых нет в оригинале.

## Важное техническое ограничение

У 4pda **нет официального публичного API**. Единственные источники данных —
серверный HTML форума и внутренние эндпоинты, которыми пользуется официальный
сайт/приложение. Поэтому весь доступ к данным спрятан за интерфейсом
[`ForumRepository`](app/src/main/java/dev/qmurzik/forpda/data/repository/ForumRepository.kt),
а реальная реализация будет либо:

- парсить HTML-страницы форума через Jsoup
  ([`ForpdaHtmlParser`](app/src/main/java/dev/qmurzik/forpda/data/network/ForpdaHtmlParser.kt) —
  каркас со заглушечными CSS-селекторами, которые нужно подобрать под живую
  вёрстку), либо
- дергать внутренние эндпоинты напрямую, если они окажутся доступны и
  достаточно стабильны.

Риски такого подхода: верстка форума может измениться в любой момент (парсер
сломается), возможна защита от автоматических запросов, и стоит свериться с
правилами форума на предмет допустимости неофициальных клиентов.

Сейчас вместо реального парсера подключён
[`FakeForumRepository`](app/src/main/java/dev/qmurzik/forpda/data/repository/FakeForumRepository.kt)
с тестовыми данными — это позволяет разрабатывать и демонстрировать UI, не
дожидаясь готового парсинга.

## Стек

- Kotlin, Jetpack Compose, Material 3 (динамические цвета, тёмная тема)
- Navigation-Compose (граф — [`ForPdaNavHost`](app/src/main/java/dev/qmurzik/forpda/navigation/ForPdaNavHost.kt))
- Hilt (DI)
- Retrofit/OkHttp + Jsoup (сеть и парсинг HTML)
- Room, DataStore — под кэш и настройки (пока не подключены)
- Coil — загрузка изображений/аватаров

## Что уже есть (каркас)

- Дерево форумов → список тем → чтение сообщений в теме, с mock-данными
- Экран логина (форма, привязана к `ForumRepository.login`, пока фейковая)
- Поиск по темам
- Заготовки экранов «Закладки» и «Профиль»
- Composable для цитирования поста (заполняет черновик ответа BB-кодом)
- Нижняя навигация, Material You тема со светлой/тёмной темой

## Чего пока нет / следующие шаги

1. **Реальный доступ к данным**: разобрать живую вёрстку 4pda, заполнить
   селекторы в `ForpdaHtmlParser`, реализовать `ForumRepository` поверх него
   и переключить `RepositoryModule` на неё.
2. **Авторизация**: cookie-based логин, скорее всего через встроенный
   WebView (форма логина форума может быть защищена от прямых POST-запросов).
3. **Рендер BB-кода/HTML постов**: сейчас теги просто вырезаются; нужен
   normальный рендер (цитаты, спойлеры, код, инлайн-картинки) через
   `AnnotatedString` или встроенный WebView для сложных постов.
4. **Кэш offline**: Room-сущности для тем/сообщений, чтение без сети.
5. **Личные сообщения, уведомления**: поскольку push от форума нет, только
   поллинг через WorkManager.
6. **То, чем клиент может быть лучше оригинала**: закладки с бейджами
   непрочитанного (вместо email-подписки), быстрые жесты (свайп для цитаты/
   шаринга), полноценная тёмная тема, адаптивный layout для планшетов,
   локальный поиск по кэшу.

## Известное ограничение текущего окружения

В этой песочнице нет Android SDK и нет доступа к репозиториям Google/Maven
(корпоративный прокси их не пропускает), поэтому `gradle` не может
зарезолвить Android Gradle Plugin и полноценно собрать проект здесь. Структура
и код написаны по стандартным для Android Studio + Compose шаблонам, но
реальную сборку и прогон нужно делать в среде с Android SDK (Android Studio
или CI с настроенным `sdk.dir`).
