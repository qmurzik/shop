# Сердце Двух Лун 🌙💞🌙

Романтическая веб-RPG (визуальная новелла) на чистых HTML/CSS/JS — без сборщиков и внешних зависимостей. Адаптирована под мобильные устройства.

## Сюжет

Вы приезжаете в приморский город Лунхейвен, унаследовав дом покойной тёти — последней Хранительницы древней реликвии «Сердце Двух Лун». Знакомясь с тремя жителями города — капитаном стражи Элиасом, бардессой Лирой и хранительницей архива Кассией — вы выбираете, кому довериться, помогаете городу пережить магическую бурю и в финале решаете, как сложатся ваши отношения. Шесть возможных концовок зависят от ваших решений.

## Возможности

- Полноценный сюжет: пролог + 5 глав + эпилог, три романтические линии.
- Система выбора, влияющая на характеристики (Обаяние / Смелость / Мудрость) и привязанность персонажей.
- Инвентарь и механика подарков — предмет, подходящий вкусу персонажа, даёт больше очков.
- Галерея воспоминаний (достижения), открывающихся по ходу истории.
- Сохранения (автосохранение + 3 ручных слота) в `localStorage`.
- Настройки: скорость текста, снижение анимации.
- Полностью адаптивный интерфейс для телефонов, планшетов и десктопа, с поддержкой safe-area для устройств с вырезом экрана.

## Запуск

Игра не требует сборки — достаточно любого статического HTTP-сервера.

```bash
npm start
# затем откройте http://localhost:3000
```

Либо откройте `index.html` напрямую в браузере.

## Структура проекта

```
index.html      — разметка всех экранов
css/style.css   — адаптивные стили
js/data.js      — сюжет, персонажи, предметы, сцены
js/engine.js    — игровое состояние, сохранения, переходы
js/ui.js        — рендер экранов и модальных окон
js/main.js      — инициализация и обработчики событий
server.js       — минимальный статический сервер для локального запуска
```

## Технические детали

- Без фреймворков и сборщиков — обычные `<script>`-теги, совместимо с любым статическим хостингом (включая GitHub Pages).
- Сохранения хранятся только в браузере пользователя (`localStorage`), сервер не хранит никаких данных.
