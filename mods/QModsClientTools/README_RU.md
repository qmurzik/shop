# QMods Client Tools 1.2.1 — Forge 1.8.9

Лёгкий клиентский мод для точной стрельбы из лука и красивого HUD. На сервер устанавливать не нужно.

## Возможности

### Лук и упреждение

- Линия полёта появляется только во время натяжения лука.
- Учитываются реальная сила натяжения, гравитация стрелы, сопротивление воздуха и воды, движение стрелка.
- Проверяются столкновения с блоками и хитбоксами сущностей.
- Цвет линии меняется при попадании в сущность.
- Маркер конца траектории показывает рассчитанное место столкновения.
- Для движущейся цели рассчитывается упреждение с учётом её сглаженной скорости, дальности и времени полёта.
- Заметный маркер около прицела показывает требуемое упреждение и время полёта.
- Мягкое доведение плавно корректирует yaw/pitch к рассчитанной точке без резкого рывка.
- Цель выбирается прежде всего по близости к перекрестию; дальность используется только при почти равном угле.
- Игроки за стенами полностью исключаются из выбора, а союзники BedWars автоматически игнорируются.
- Можно ограничить выбор только игроками, изменить дальность и угол выбора цели.

### Текстовые бинды

- Восемь независимых слотов.
- Каждый слот хранит клавишу и произвольный текст или команду.
- По умолчанию первый слот: клавиша `I`, команда `/hub`.
- Клавиша Backspace/Delete при назначении снимает бинд.

### Красивый чат

- Темы: `Стекло`, `Неон`, `Карточки`, `Минимал`, `Сакура`, `QMods`.
- Настраиваемые прозрачность и цвет акцента.
- Плавное появление сообщений, тень текста и необязательное время `HH:mm`.
- Подсказка по эмодзи над строкой ввода.
- Каждая кнопка эмодзи кликабельна и вставляет комбинацию в текущую позицию курсора.
- Панель содержит 16 комбинаций, включая `:)`, `<3`, `:D`, `;)`, `:P`, `:(`, `^^`, `:O`, `:/`, `:*`, `xD`, `B)`, `:3`, `:'(` и `o_O`.
- Команды, начинающиеся с `/`, не изменяются.

### Scoreboard

- Те же шесть полноценных тем оформления.
- Цвет акцента, прозрачность, масштаб, левая/правая сторона.
- Отдельное включение числовых значений.
- Оригинальный scoreboard полностью отключается до отрисовки нового.

### MineBlaze BedWars

- Автоопределение матча по `BEDWARS` и адресу `mineblaze.net`.
- Компактный HUD: время матча, сломанные кровати, финальные и обычные убийства.
- Счётчики железа, золота, алмазов, изумрудов и стрел из инвентаря.
- Крупное предупреждение после уничтожения своей кровати.
- Технические красные числа справа от scoreboard скрываются только в BedWars MineBlaze.
- Строки сломанных кроватей, финальных и обычных убийств убираются из scoreboard: статистика остаётся в отдельном HUD, а в таблице — команды и состояние матча.
- В магазине товары получают заметную рамку, заливку, знак `✓/×` и подробную подсказку стоимости при наведении.
- Клавиши `1–9` выбирают девять верхних вкладок магазина; автоматических покупок нет.
- Автоперезаход при подтверждённом падении в бездну: `/leave`, настраиваемая задержка (по умолчанию 1 секунда), затем `/rejoin`.
- Есть отдельный назначаемый бинд ручного перезахода и регулируемый порог высоты.

### Локальная внешность

- Скин Киры и плащ QMods отображаются только на этом клиенте и не меняют аккаунт или серверные данные.
- Обычные плащи других игроков продолжают отображаться.
- Оба элемента можно независимо отключить на вкладке `Внешность`.

## Исправлено в 1.2.1

- Помощь при стрельбе больше не захватывает далёкую цель вместо игрока у перекрестия и не выбирает цель сквозь стену.
- Исправлен быстрый выбор вкладок магазина.
- Добавлено переназначение клавиши меню прямо в QMods; команда `/qtools` всегда остаётся запасным способом входа.
- Перетаскивание ползунка больше не переключает соседние тумблеры.
- Панель эмодзи расширена, а кнопки вставляют комбинацию в текущую позицию курсора.
- Исправлен `NoSuchFieldError: layerRenderers` при запуске 1.2.0; рендереры скина и плаща теперь корректно преобразованы для обычного Forge.

## Установка

1. Установить Minecraft 1.8.9 и Forge `11.15.1.2318`.
2. Удалить прежние версии мода и положить `QMods-Client-Tools-1.8.9-1.2.1.jar` в `.minecraft/mods`.
3. Удалить старый `AimBow-1.0.jar`, чтобы две траектории не рисовались одновременно.
4. Открыть настройки клавишей `Right Shift` или командой `/qtools`; клавишу меню можно переназначить внизу окна.
5. Клавиша `P` быстро включает и выключает траекторию.

## Рекомендуемые настройки для Intel HD Graphics 4000

- Лёгкий режим: включён.
- Частота расчёта: раз в 2 тика.
- Сегменты: 140–180.
- Дальность: 64–72 блока.
- Поле выбора: 25–30 градусов.
- Для Minecraft достаточно 2–3 ГБ выделенной памяти; больше не ускорит слабый процессор.

Настройки сохраняются в `.minecraft/config/qmodstools.cfg`.

## Сборка исходников

Нужна 64-битная Java 8:

```bash
./gradlew setupDecompWorkspace
./gradlew build
```

Готовый JAR появится в `build/libs`.
